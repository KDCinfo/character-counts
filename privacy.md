# Character Counts: A Chrome Browser Extension

## Privacy Policy

The Character Counts browser extension is a simple open source utility that simply counts and converts selected characters.

- The extension shows how many characters are in a selection.
- It will also convert between ASCII (char), ASCII (int), & 8-bit (Byte).

## Single Purpose

- Counts and converts selected characters.

## Permission Justifications

- The 'activeTab' permission is needed so the script can access any highlighted text for counting, as well as count all the characters on the active page.
- The 'scripting' permission is need so the extension can perform the counting and calculation.
